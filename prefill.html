如何理解这些数字

这里包含所有主要矩阵乘法、depthwise convolution、GDN 递推和输出层；非线性、归一化等另外列账。GDN 用递推参考算法，不能直接当作任意 chunkwise kernel 的执行指令数。

Attention 仅统计因果掩码内的有效 QKᵀ / AV。已有 P 个前缀时，新 token 仍须访问前缀。将新 tokens 分块不会重置上下文；有效 pair 数仍为 TP+T(T+1)/2。

LoRA 来自保留的 Edge0 实验 header 审计：310 个 rank-16 targets，42,332,160 FLOPs/token。原版 Qwen 不加这项；此 Edge0 prefill 不执行 decode prerouter。

所有结果都是计算，不是测量。不含视觉编码器或可选 MTP；输入若含图像，必须额外核算视觉路径。

展开：归一化、激活、softmax 与门控的近似 scalar-operation 账目

加减乘除及 exp / log / rsqrt 各计 1 次，仅便于列账；它们的硬件成本并不相同。这些数不自动加进上面的主体 FLOPs。softmax 的 max 比较、top-k 比较、索引、量化解包、反量化、dtype 转换、RoPE 表生成及数据搬运不在该计数内。常量 −exp(A) 按一次初始化计入，chunk 分割不重复加算。

展开：符号、实现口径与来源

H=2048；I=Is=512；E=256；V=248320；L=40；La=10；Lg=30。Attention：nq=16、nkv=2、d=256，Q=nq·d=4096，R=nkv·d=512。GDN：nk=16、nv=32、dk=dv=128，Dk=nk·dk=2048，Dv=nv·dv=4096，卷积宽度 c=4。

Attention 的 Q+gate 输出宽度为 8192，而不是普通 Q 的 4096。GDN 投影、卷积、状态更新与门控都单列，不能用普通 attention 层乘 40 代替。

GDN 状态计算：衰减 dk；k·state 为 2dk；delta 两次标量操作；rank-one 更新 2dk；q·state 为 2dk。合计每 value head、每 value channel 为 7dk+2。

GDN chunkwise 实现可能增加块内 Gram 矩阵和三角运算；masked attention 也可能执行额外 tile。当前公式作为统一的逻辑参考，不是这类实现的精确算子 trace。
